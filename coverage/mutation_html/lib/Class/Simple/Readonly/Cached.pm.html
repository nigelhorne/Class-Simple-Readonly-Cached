   58: =head1 SYNOPSIS
   59: 
   60: A caching decorator for L<Class::Simple>-based (and arbitrary) objects.
   61: 
   62: It is up to the caller to maintain the cache if the object comes out of
   63: sync with the cache, for example by changing its state.
   64: 
   65:     use Class::Simple::Readonly::Cached;
   66: 
   67:     my $obj = Class::Simple->new();
   68:     $obj->val('foo');
   69:     my $cached = Class::Simple::Readonly::Cached->new(
   70:         object => $obj,
   71:         cache  => {},
   72:     );
   73: 
   74:     my $val  = $cached->val();   # calls the real object
   75:     my $val2 = $cached->val();   # served from cache
   76: 
   77:     $val = $cached->val(a => 'b');   # args form part of the cache key
   78: 
   79: Note that when the object goes out of scope (DESTROY is called), the
   80: cache is cleared automatically.
   81: 
   82: =head1 DESCRIPTION
   83: 
   84: Wraps any Perl object in a transparent caching layer.  Every method call
   85: is intercepted via AUTOLOAD; on the first call (a I<miss>) the result is
   86: stored in the cache and returned.  Subsequent identical calls (same method
   87: name, same argument list) are I<hits> and are served directly from the
   88: cache without touching the inner object.
   89: 
   90: Two cache backends are supported: a plain hash reference (fast, in-process,
   91: no expiry) and any CHI-compatible object (persistent, shared, with expiry).
   92:

  561: =head1 LIMITATIONS
  562: 
  563: =over 4
  564: 
  565: =item B<Not safe for mutable objects>
  566: 
  567: The cache is never invalidated automatically.  If the inner object's
  568: state changes after caching, the wrapper will return stale data.  The
  569: caller must either reset the cache manually or avoid using this module
  570: with objects that mutate.
  571: 
  572: =item B<Argument serialisation is naive>
  573: 
  574: Cache keys are built by joining defined arguments with C<::>.  Two
  575: different argument lists can therefore produce the same key if an
  576: argument itself contains C<::> (e.g. C<foo('a::b', 'c')> vs
  577: C<foo('a', 'b::c')>).  Callers that pass arguments containing C<::>
  578: should use a CHI backend with a custom key serialiser.
  579: 
  580: =item B<Undefined arguments are collapsed>
  581: 
  582: Undefined values in the argument list are silently dropped from the
  583: cache key, so C<foo(undef)> and C<foo()> share a cache entry.
  584: 
  585: =item B<Scalar-then-list context mismatch is a miss>
  586: 
  587: If a method is first called in scalar context and then in list
  588: context with identical arguments, the second call is a cache miss
  589: and re-invokes the inner object.  Both results are then independently
  590: cached.
  591: 
  592: =item B<C<can('new')> returns a code reference, not a boolean>
  593: 
  594: For strict correctness C<can> returns C<\&new> for the C<'new'>
  595: method rather than the boolean C<1>.  The code reference is callable
  596: but callers who compare it with C<==> to C<1> will see a mismatch.
  597: 
  598: =item B<Does not work with L<Memoize>>
  599: 
  600: C<Memoize> intercepts at the symbol-table level and conflicts with
  601: the C<AUTOLOAD> dispatch used here.
  602: 
  603: =back

  657: =head1 FORMAL SPECIFICATION
  658: 
  659: =head2 new
  660: 
  661:     new : (C x P) -> (W | undef)
  662: 
  663:     C = class name string
  664:     P = { cache : (HashRef | CacheObj), object? : Ref, quiet? : Bool, ... }
  665:     W = blessed P in C
  666: 
  667:     valid_cache(c) :=
  668:         ref(c) = 'HASH'
  669:         OR ( blessed(c) AND c.can('get') AND c.can('set') AND c.can('purge') )
  670: 
  671:     Precondition:
  672:         valid_cache(P.cache)
  673: 
  674:     Double-wrap invariant:
  675:         forall o in Dom(cached): new(C, {object: o, ...}) = cached[o].object
  676: 
  677:     Clone (object invocation):
  678:         forall w : W: w.new(P') = bless( merge(w, P'), ref(w) )
  679: 
  680: =head2 object
  681: 
  682:     object : W -> Ref
  683: 
  684:     forall w : W: object(w) = w.object
  685: 
  686: =head2 state
  687: 
  688:     state : W -> HashRef
  689: 
  690:     forall w : W: state(w) = { hits => w._hits, misses => w._misses }
  691: 
  692: =head2 can
  693: 
  694:     can : (W|Str x Str) -> (CodeRef | undef)
  695: 
  696:     forall w : W, m : Str:
  697:       can(w, 'new') = \&new
  698:       can(w, m)     = w.object.can(m)  OR SUPER::can(w, m)
  699: 
  700: =head2 isa
  701: 
  702:     isa : (W x Str) -> Bool
  703: 
  704:     forall w : W, c : Str:
  705:       isa(w, c) = 1  if c in { ref(w), 'Class::Simple::Readonly::Cached' }
  706:                | 1  if SUPER::isa(w, c)
  707:                | w.object.isa(c)  if ref(w)
  708:                | 0  otherwise
  709: 
  710: =head2 autoload
  711: 
  712:     autoload : (W x M x A*) -> R
  713: 
  714:     M  = method name string
  715:     A* = argument tuple (possibly empty)
  716:     R  = scalar | list | undef
  717: 
  718:     Cache key:
  719:         k(w, m, a) := ref(w) ++ '::' ++ m ++ '::' ++ defined_args(a)
  720: 
  721:     Caching law:
  722:         get(cache(w), k(w,m,a)) = v, v != undef
  723:             => autoload(w, m, a) = v          (cache hit)
  724:         get(cache(w), k(w,m,a)) = undef
  725:             => v = w.object.m(a)
  726:                set(cache(w), k(w,m,a), v)
  727:                autoload(w, m, a) = v          (cache miss)
