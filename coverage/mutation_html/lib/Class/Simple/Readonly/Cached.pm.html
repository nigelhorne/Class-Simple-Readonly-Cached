   58: =head1 SYNOPSIS
   59: 
   60: A caching decorator for L<Class::Simple>-based (and arbitrary) objects.
   61: 
   62: It is up to the caller to maintain the cache if the object comes out of
   63: sync with the cache, for example by changing its state.
   64: 
   65:     use Class::Simple::Readonly::Cached;
   66: 
   67:     my $obj = Class::Simple->new();
   68:     $obj->val('foo');
   69:     my $cached = Class::Simple::Readonly::Cached->new(
   70:         object => $obj,
   71:         cache  => {},
   72:     );
   73: 
   74:     my $val  = $cached->val();   # calls the real object
   75:     my $val2 = $cached->val();   # served from cache
   76: 
   77:     $val = $cached->val(a => 'b');   # args form part of the cache key
   78: 
   79: Note that when the object goes out of scope (DESTROY is called), the
   80: cache is cleared automatically.
   81: 
   82: =head1 DESCRIPTION
   83: 
   84: Wraps any Perl object in a transparent caching layer.  Every method call
   85: is intercepted via AUTOLOAD; on the first call (a I<miss>) the result is
   86: stored in the cache and returned.  Subsequent identical calls (same method
   87: name, same argument list) are I<hits> and are served directly from the
   88: cache without touching the inner object.
   89: 
   90: Two cache backends are supported: a plain hash reference (fast, in-process,
   91: no expiry) and any CHI-compatible object (persistent, shared, with expiry).
   92:

  580: =head1 LIMITATIONS
  581: 
  582: =over 4
  583: 
  584: =item B<Not safe for mutable objects>
  585: 
  586: The cache is never invalidated automatically.  If the inner object's
  587: state changes after caching, the wrapper will return stale data.  The
  588: caller must either reset the cache manually or avoid using this module
  589: with objects that mutate.
  590: 
  591: =item B<Argument serialisation is naive>
  592: 
  593: Cache keys are built by joining defined arguments with C<::>.  Two
  594: different argument lists can therefore produce the same key if an
  595: argument itself contains C<::> (e.g. C<foo('a::b', 'c')> vs
  596: C<foo('a', 'b::c')>).  Callers that pass arguments containing C<::>
  597: should use a CHI backend with a custom key serialiser.
  598: 
  599: =item B<Undefined arguments are collapsed>
  600: 
  601: Undefined values in the argument list are silently dropped from the
  602: cache key, so C<foo(undef)> and C<foo()> share a cache entry.
  603: 
  604: =item B<Scalar-then-list context mismatch is a miss>
  605: 
  606: If a method is first called in scalar context and then in list
  607: context with identical arguments, the second call is a cache miss
  608: and re-invokes the inner object.  Both results are then independently
  609: cached.
  610: 
  611: =item B<C<can('new')> returns a code reference, not a boolean>
  612: 
  613: For strict correctness C<can> returns C<\&new> for the C<'new'>
  614: method rather than the boolean C<1>.  The code reference is callable
  615: but callers who compare it with C<==> to C<1> will see a mismatch.
  616: 
  617: =item B<Does not work with L<Memoize>>
  618: 
  619: C<Memoize> intercepts at the symbol-table level and conflicts with
  620: the C<AUTOLOAD> dispatch used here.
  621:

  676: =head1 FORMAL SPECIFICATION
  677: 
  678: =head2 new
  679: 
  680:     new : (C x P) -> (W | undef)
  681: 
  682:     C = class name string
  683:     P = { cache : (HashRef | CacheObj), object? : Ref, quiet? : Bool, ... }
  684:     W = blessed P in C
  685: 
  686:     valid_cache(c) :=
  687:         ref(c) = 'HASH'
  688:         OR ( blessed(c) AND c.can('get') AND c.can('set') AND c.can('purge') )
  689: 
  690:     Precondition:
  691:         valid_cache(P.cache)
  692: 
  693:     Double-wrap invariant:
  694:         forall o in Dom(cached): new(C, {object: o, ...}) = cached[o].object
  695: 
  696:     Clone (object invocation):
  697:         forall w : W: w.new(P') = bless( merge(w, P'), ref(w) )
  698: 
  699: =head2 object
  700: 
  701:     object : W -> Ref
  702: 
  703:     forall w : W: object(w) = w.object
  704: 
  705: =head2 state
  706: 
  707:     state : W -> HashRef
  708: 
  709:     forall w : W: state(w) = { hits => w._hits, misses => w._misses }
  710: 
  711: =head2 can
  712: 
  713:     can : (W|Str x Str) -> (CodeRef | undef)
  714: 
  715:     forall w : W, m : Str:
  716:       can(w, 'new') = \&new
  717:       can(w, m)     = w.object.can(m)  OR SUPER::can(w, m)
  718: 
  719: =head2 isa
  720: 
  721:     isa : (W x Str) -> Bool
  722: 
  723:     forall w : W, c : Str:
  724:       isa(w, c) = 1  if c in { ref(w), 'Class::Simple::Readonly::Cached' }
  725:                | 1  if SUPER::isa(w, c)
  726:                | w.object.isa(c)  if ref(w)
  727:                | 0  otherwise
  728: 
  729: =head2 autoload
  730: 
  731:     autoload : (W x M x A*) -> R
  732: 
  733:     M  = method name string
  734:     A* = argument tuple (possibly empty)
  735:     R  = scalar | list | undef
  736: 
  737:     Cache key:
  738:         k(w, m, a) := w._class ++ '::' ++ m ++ '::' ++ defined_args(a)
  739:         (w._class = ref(w), pre-computed once in new() to avoid ref() per dispatch)
  740: 
  741:     Caching law:
  742:         get(cache(w), k(w,m,a)) = v, v != undef
  743:             => autoload(w, m, a) = v          (cache hit)
  744:         get(cache(w), k(w,m,a)) = undef
  745:             => v = w.object.m(a)
  746:                set(cache(w), k(w,m,a), v)
  747:                autoload(w, m, a) = v          (cache miss)
